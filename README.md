# TASKY — Android Studio Project

TASKY is a task-management Android app built with Kotlin, Android XML layouts, and local SQLite storage.

## Open and run
1. Extract the ZIP.
2. Open the `TASKY` folder (containing `settings.gradle.kts`) in Android Studio.
3. Sync Gradle and run on an Android emulator or device.
4. Allow notifications if you want deadline and overdue alerts.

## Included functionality
- Create, edit, complete, reopen, and delete categorized tasks.
- Task priority, difficulty, estimated duration, deadlines, and progress.
- Keyword search and category, priority, status, and deadline filters.
- Dashboard, calendar, suggested schedule, deadline pressure warnings, and saved availability window.
- Workload monitoring, focus sessions, breaks, distraction tracking, and reminder notifications.

## Notes for evaluation
- Data is stored locally on the device in SQLite. Removing the app or clearing its data may delete tasks.
- Verify behavior on the target Android device before submission.
- This archive has been structurally checked, but it has not been compiled or run in this environment.
- The original project contains local/mock account workflows; do not assume production-grade authentication or cloud sync.
